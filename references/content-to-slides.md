# 材料到页级表达

## 叙事顺序

根据听众、汇报时长和材料选择顺序：

- 论文：背景与缺口、问题、方法、实验或案例、结论与局限。
- 项目进展：目标、本阶段任务、完成情况、证据、风险与下一步。
- 开题或方案：问题与范围、目标、方案、验证路径、计划。
- 综述：主题与范围、分类依据、代表研究、比较与综合、待解决问题。

页级提纲写清每页任务、主要证据和版式。主报告页数与PDF总页数分别估算，计数口径见[模板规范](template-spec.md)。

## 页面表达

每页围绕一个重点组织：标题给出判断或问题，主旨句说明关键联系或结果，主体承载证据，出处交代来源和条件。口头展开写入备注。

| 内容 | 版式与重点 |
|---|---|
| 框架、机制、过程 | 主旨句＋主图，说明输入、输出与环节联系 |
| 结果、对比 | 图表呈现条件、基线、指标与主要差异 |
| 背景、目标、总结 | 用要点、双栏或block组织信息 |
| 公式、推导 | 公式与符号、假设一起呈现，详细推导放附录 |
| 跨研究比较 | 采用相同维度，注明信息缺失与判断依据 |

结论条用于核心判断。页面拥挤时删去重复内容、拆页或重画图，保持文字可读。

## 证据与措辞

背景判断、相关研究归纳和研究补位标注来源，区分作者结论、汇报者归纳与推断。概念图、教学情境和示例数据标明性质；结论与计算实验、历史回放或现场执行各自支持的范围一致。

相关工作交代已有方法的能力、条件与缺口。优先核对原材料引用，缺少书目信息时标注待核验。

压缩时保留研究问题、关键机制、主图、核心结果与证据条件，将重复定义和次要推导移至附录。术语前后一致，句子简短，判断具体。
